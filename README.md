# 🤖 AI Smart Hiring Copilot

**AI-Driven Smart Hiring Platform with Candidate Matching Copilot**

AI Smart Hiring Copilot is an AI-powered recruitment platform designed to assist **HR professionals and recruiters** in streamlining the hiring process. The system uses AI to support job description creation, candidate evaluation, matching, ranking, comparison, and interview preparation.

## 🎯 Project Objective

The main objective of this project is to reduce the manual effort involved in recruitment by providing recruiters with an intelligent **AI Copilot** that assists throughout the candidate selection process.

## ✨ Key Features

* 📄 **Job Description Module** – Helps create and analyze job descriptions.
* 🎯 **Candidate Matching & Ranking** – Matches candidates with job requirements and provides suitability scores.
* ⚖️ **Candidate Comparison** – Enables head-to-head comparison of candidates.
* 🎤 **Interview Script Engineer** – Assists in generating role-specific interview questions and scripts.
* 💻 **Coding Sandbox** – Supports technical and coding interview evaluation.
* 🧠 **Resume Intelligence Chat** – Allows recruiters to interact with and extract insights from candidate resumes.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/janavishetty07/AI-Smart-Hiring-Copilot.git
cd AI-Smart-Hiring-Copilot
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python -m streamlit run copilot_app.py
```
